# Creative and Asset Pipeline

## Two uses of generation

**Ideation:** Use image, video, audio, voice, music, or 3D generation to widen the search space, reveal missing traits, compare styles, prototype timing, and help the agent reason visually or aurally. Generated work may be discarded after it improves the specification.

**Production candidate:** A generated artifact intended for the game enters a gated asset pipeline. It is never accepted solely because it is usable.

## Creative Direction Pack

For a main game or visual/audio-heavy Goal, establish and version:

- player fantasy and emotional arc;
- reference and anti-reference boards;
- shape language, composition, camera and motion grammar;
- color bible with semantic roles and lighting transformations;
- material/texture language and acceptable detail density;
- UI motion, feedback, typography and accessibility principles;
- audio palette, dynamics, spatial behavior and silence;
- representative target captures and explicit failure examples.

Capture the intended feeling without copying protected expression. Translate references into traits and constraints.

## Variant loop

1. Research real-world and genre constraints.
2. State the design hypothesis and evaluation criteria.
3. Generate multiple materially different variants; do not default to the first.
4. Inspect outputs with a vision/audio-capable model and compare against the Creative Direction Pack.
5. Extract useful traits, reject artifacts and generic AI signatures, then refine or synthesize.
6. If production-bound, convert to an editable source artifact and optimize for the engine.
7. Validate in context at target camera, lighting, scale, platform, and performance budget.

## Production gate

Require provenance, generator/model/settings where available, source prompts or procedural scripts, license and commercial-use status, third-party input rights, editable sources, engine import settings, naming, dimensions/scale, LOD/compression, accessibility, style comparison captures, and performance evidence.

Reject content with uncertain rights, hidden watermarks, malformed topology, inconsistent material response, visual noise, broken loops, audible artifacts, unreadable UI, mismatched style, excessive cost, or unverifiable provenance.

Programmatic Blender, shader, audio, or conversion scripts remain authoritative when they generate assets. Modify and rerun the source rather than hand-editing only the output.

## Tool choice

Discover available generation tools at runtime. Image generation is useful for level/material/UI ideation; video for motion, camera, VFX, and trailers; audio/voice for timing, character, ambience, and feedback; 3D for blockout and candidate meshes. Tool availability never removes the quality and rights gates.
